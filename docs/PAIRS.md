# Пары языков переводчика (22.10.2026)

Направление перевода задаёт проект: `"pair": "<источник>-<цель>"` в `project.json`, языки `hu`, `ru`, `en` в обе
стороны. Без ключа — `hu-ru` (прежнее поведение, побайтно). Код — `src/langs.py`; где пара влияет — ниже.

| Что | hu-ru | ru-en | ru-hu, en-ru, hu-en, en-hu |
|---|---|---|---|
| Промпт перевода | исходный русский (`translate.SYSTEM`) | `SYSTEM_RU_EN` | `system_generic`: языки, десятичный знак, единицы, кавычки цели |
| Проверки сегмента | `check` (венгерский, отрицания, действия, латиница) | `check_en` | `check_generic`: числа с разрядами, латиница русского источника, остатки языка источника |
| Постобработка | `fix_caps` + `fix_units`, `first_use` | — | `fix_units`, если цель — русский |
| Разбор отрицаний (morph) | да | — | если источник — венгерский |
| Смысловая проверка | исходная, автоисправления включены | RU→EN, автоисправления выключены | общий промпт RU→EN с языками пары, автоисправления выключены |
| Шлифовка по соглашениям | да | нет | нет |
| Сокращение под место в PDF | исходные промпты | общий английский промпт | общий английский промпт |
| OCR (Tesseract / портал) | `hun` / промпт с венгерскими буквами | `rus+eng` | по языку источника: `hun`, `rus+eng`, `eng` |
| Надписи скриншотов | да | нет | только источник `hu` |
| Файл перевода | `_RU` | `_EN` | `_<ЦЕЛЬ>` |

Автоисправления смысловой проверки можно задать явно: `"review_autofix": true|false` в `project.json`.

**Глоссарий обратного направления.** Таблица глоссария с шапкой в обратную сторону (`| Венгерский | Русский |` у пары
`ru-hu`) читается развёрнутой: термин цели становится ключом, раздел «Правила применения» (он о другом направлении) не
берётся, пометки «строгий» сохраняются. Свой глоссарий проекта с шапкой своего направления (`| Русский | Английский |`)
читается как записан. Шапка — первые две ячейки строки, названия языков: русский/венгерский/английский, magyar,
orosz, angol, Hungarian, Russian, English.

**Не проверено / не поддержано.** Пары кроме hu-ru и ru-en проверены только короткими документами (по одному на
направление). Правила вёрстки PDF (`docx_build`, `docx_layout`, роли строк) настраивались на венгерских документах; для
PDF на других языках источника они работают, но не выверены. Веб-сервис: пара берётся из проекта, но экраны глоссария
и эксперта (`server/glossary_db.py`, `server/expert.py`) — только «венгерский — русский». В образ добавлены языки
Tesseract `rus`, `eng` (нужна пересборка).
