# Договор правил вёрстки — план (утверждён Максимом 20.10)

## Зачем

19.10 при печати сканов раз за разом находились новые дефекты. Разбор девяти находок дня: большинство — конфликты
правил, в основном меток портала (`roles.py`, с 18.10) против геометрических правил (оглавление, сетка без линеек,
колонтитулы, отступы списков); остальные — непокрытые случаи (распознавание знаков). Проверка не ловила поломки:
регрессия сравнивала число листов, сканы собирались из сегментов от 16.10, глазами смотрелись выборочные листы.

## Шаги (порядок важен)

0. **Опись правил** — `RULES.md`: каждое правило пяти модулей (`docx_struct`, `docx_layout`, `docx_build`,
   `segments`, `layout`, плюс `roles`, `docx_profile`): что решает (роль строки, отступ, таблица, заголовок,
   колонтитул…), на чём основано (геометрия оригинала / метка портала / профиль / стиль / текст), на каком документе
   появилось, какой тест держит. Выход — и список пар правил, решающих одно и то же.
1. **Эталон и регрессия по картинкам** — `tools/visual_regress.py`: пересборка всех документов (15 регрессии, сканы
   на текущем распознавании из кэша, венгерские — из ночного прогона 20.10), рендер листов, сравнение с эталоном
   (при сдвиге листов — сопоставление по тексту), на выходе — только изменившиеся листы парами «было | стало».
   Эталон — сборки после утренней проверки 20.10; делается ДО рефакторинга.
2. **Порядок старшинства** — одна функция решения роли строки/абзаца по таблице: геометрия оригинала (строка
   оглавления с номером листа справа, тире в слое, ячейка сетки, стабильный колонтитул) → метка портала → профиль.
   Разрозненные проверки — через неё. Тесты табличные: «факт геометрии × метка портала → роль».
3. **Один источник отступов списков** — место маркера и текста всегда по оригиналу (geo) для разметки, текстового
   слоя и сканов; профиль — только запас. Прочие три пути — прочь.
4. **Ред-тим** — 2–3 агента читают опись и функцию старшинства, ищут пары правил, которые могут столкнуться, и на
   каждую строят синтетический документ с известным ответом (`tools/synth_bench.py`); расхождение — дефект с готовым
   тестом. Картинки агенты не судят (выдумывают разметку). Отдельно — red-team на дифф шагов 2–3.
5. **Приёмка** — регрессия по картинкам: только ожидаемые изменения; тесты (с синтетическими) — зелёные; слияние в
   master — после OK Максима, без push.

документ — новый процесс, код читается с диска). Оценка: ~1,5 дня.
