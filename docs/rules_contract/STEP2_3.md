## Шаг 2 — старшинство источников роли строки

Одна функция `docx_layout._role(факты)` решает роль строки PDF без разметки (скан, текстовый слой): колонтитул,
заголовок, пункт, строка оглавления, абзац. Прежде каждое правило решало само, в своём месте `load`. PDF с тегами
решает `docx_struct` по тегам, сюда он не доходит — теги старше всего по маршруту конвейера.

| старшинство | источник | факт | роль |
|---|---|---|---|
| 1 | лист оригинала | строка шапки таблицы на каждом листе (N2) | абзац таблицы |
| | | повтор у края листа; скан: метка «колонтитул», похожая на всех листах | колонтитул (из текста прочь) |
| | | знак маркера: тире текстового слоя скана, «•»/«–»/знак Symbol в начале строки, сегмент-маркер слева | пункт |
| | | номер листа в конце строки — у правого поля или дальше 60 pt от текста (`_toc_line`) | строка оглавления |
| | | название раздела: скан — метка «колонтитул», меняющаяся от раздела к разделу; повтор вверху следующего листа | заголовок |
| 2 | метка портала | «заголовок» / «пункт» | заголовок / пункт |
| | | «текст», «подпись», «таблица»; «колонтитул» на текстовом слое | абзац: правила вида строки на размеченном листе не применяются |
| 3 | правила вида строки (лист без меток) | короткий полужирный по центру; в текстовом слое — и с номером у края | заголовок |
| | | «a)», «1)», «a.)» в начале | пункт |
| | | остальное | абзац; склейка строк в абзац и в пункт — только на листе без меток |

Заголовок — только строка из одного куска (как и было): строка из нескольких кусков («1.1. ⇥ ÜV-4 …» скана) —
абзац с табуляцией по месту оригинала. Проверено обратное: заголовком по метке такая строка выходила хуже оригинала
(номер у поля, название у табуляции стиля, без полужирного; 3PR42 л. 4) — откачено.

Решатель вызывается в двух местах `load`: при снятии колонтитулов (факты повтора и метки) и на каждой строке потока
(остальные факты). Знак маркера — одна функция `sign_of` и для роли строки, и для сетки без линеек (`_grids`).

## Шаг 3 — один источник отступов пунктов

`docx_build.item_ind(список, уровень, профиль, база)` → (маркер, текст), pt — единственное место, где решается отступ
пункта:

- место списка на листе оригинала (`geo`) — всегда, если оно есть (прежде — только если расходилось с профилем больше
  чем на 3 pt, и только в абзац): разметка (`docx_struct.list_geo`), текстовый слой и скан (`docx_layout`);
- `list_geo` — и у списков в ячейках таблиц, и у списков из однострочных пунктов (начало текста — первый прогон с
  буквой, если он правее метки на 3 pt и больше; метка, снятая из текста, оставляет прогону своё место — тогда места
  нет; прежде место бралось только по второй строке пункта);
- база в ячейке — край текста столбца на листе: линия столбца + поле ячейки оригинала, без линий — левый край текста
  столбца (не начало текста самой ячейки: у ячейки из одного вложенного списка маркер вставал к краю — JPDS);
- профиль (`lists_kind`, `lists`, формула по умолчанию) — запас, когда места нет; `lists` больше не считает пункты в
  ячейках (их отступ — от края столбца, не от поля листа: ТЭ357);
- место под метку (римские — 24 pt, знаки — 9 pt; иначе текст уезжает к следующей табуляции) — к обоим источникам;
- одно значение — и в нумерации (свой `abstractNum` на значение уровня), и прямо в абзаце (прежде: в абзаце место по
  листу, в нумерации — профиль);
- текстовый слой: место текста пункта со знаком в тексте («•⇥Normal …») — по второй строке пункта (висячий отступ
  оригинала), а не по ширине «• »; маркер отдельным сегментом слева от пункта в несколько строк узнаётся по первой
  строке пункта (прежде — по середине всего сегмента, и маркер Symbol Eskom не узнавался);
- текст пункта левее поля набора — к полю (у скана 3PR42 тире на 9,6 pt и текст на 0,8 pt левее поля: место
  отбрасывалось правилом master, пункт брал испорченный профиль документа — текст на 155 pt от поля).

Проверки: **Ф7** сверяет у каждого пункта отступ абзаца с нумерацией его уровня («одно значение») и нумерацию пунктов
тела — с источником сборки (`item_ind`); прежде видела только нумерацию и сравнивала её с профилем без места под метку
— ложные нарушения. **М2** не считает нарушением прямой отступ пунктов в ячейках («List Cell UTS») — это значение
списка, сверяемое Ф7.
