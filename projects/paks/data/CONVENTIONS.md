# Соглашения для составления глоссария HU→RU (АЭС «Пакш», ВВЭР-440)

Документы: эксплуатационная документация АЭС «Пакш» — ИЭ реакторной установки (3PR04 KU), инструкция по действиям
при аномальных состояниях (3PR42), инструкция по ликвидации аварий второго контура (3SZ19), ПУБЭ — требования (ÜFK I)
и толкования (ÜFK II). Русский — язык российской эксплуатационной документации АЭС с ВВЭР.

Модальность: kell → необходимо; tilos → запрещается; nem kell → не требуется; lehet / -ható → допускается/можно.

## Что выписывать (плотно — всё отраслевое, даже частое)
- технические термины и именные группы (2–4 слова), сложные слова (gőzfejlesztő, hőcserélő, vákuumrontó…);
- названия систем, оборудования, арматуры, сигналов, режимов, защит, блокировок;
- глаголы-операции, особенно с приставками (felbóroz, leterhel, kiüt, élesít, bénít, leürít, feltölt, légtelenít, nyomásmentesít…);
- слова с отрицающими морфемами (-talan/-telen/-tlan/-tlen, in-) и «nem + признак» (nem sérült → неповреждённый);
- устойчивые формулы инструкций/ПУБЭ (NEM LEHET NAGYOBB, MINT → НЕ ДОЛЖНО ПРЕВЫШАТЬ; értelemszerűen → по смыслу);
- сокращения: расшифровка, если знаешь; иначе — оставлять латиницей с пометкой;
- НЕ выписывать: коды оборудования (30TL02D001, RL21S201), чистые числа, имена собственные, общие слова без отраслевого смысла
  (és, vagy, alapján, szerint, következő …).

## Формат результата — JSON-массив в файл terms_XX.json
[{"hu": "словарная форма", "forms": ["формы, встреченные в тексте", "…"], "ru": "русский термин (начальная форма)",
  "type": "термин|система|оборудование|операция|сокращение|формула|отрицание",
  "risk": "высокий|обычный", "sure": true, "example": "короткий фрагмент оригинала", "note": "пояснение/вариант/[уточнить]"}]
risk = «высокий», если перевод легко сделать неверно: отрицающая морфема, глагольная приставка, многозначность, ложный друг,
сложное слово с неочевидным русским эквивалентом, системный термин ВВЭР со своим принятым названием.
sure = false — если русский эквивалент не уверен; тогда в note: «[уточнить]» и варианты.
