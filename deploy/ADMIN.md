# Переводчик HU→RU — инструкция администратора

Сервис переводит эксплуатационную документацию с венгерского на русский через портал go.ai-rosatom.ru.
Пользователи работают в браузере, ничего не устанавливают.

**Нужно:** Linux-сервер с Docker и Docker Compose v2, 4 ГБ памяти, 10 ГБ диска, доступ с сервера к
https://go.ai-rosatom.ru.

## Установка — две команды

```bash
tar xzf hut_<дата>.tar.gz && cd hut
./install.sh
```

Скрипт спросит порт и логин с паролем администратора сервиса, запустит сервис, проверит его и покажет адрес
вида `http://<сервер>:<порт>`.

## Пользователи

```bash
./hut user add ivanov                  # переводчик; пароль скрипт спросит
./hut user add petrov --role expert    # эксперт: ведёт глоссарии
```

Пользователю сообщить три вещи: **адрес, логин, пароль**. Свой токен портала он вписывает сам в профиле
сервиса, инструкция есть в разделе «Справка».

Ещё команды: `./hut user passwd <логин>` — сменить пароль, `./hut user disable <логин>` — отключить,
`./hut user list` — все пользователи.

## Глоссарии

- Комплект «Пакш» с глоссариями заказчика уже в архиве, делать ничего не нужно.
- **Новый комплект** (проект) с глоссарием заказчика — файл docx, xlsx или md:

  ```bash
  ./hut project add <имя> <глоссарий.docx>
  ```

- **Новую версию глоссария** существующего комплекта загружает эксперт в веб-интерфейсе: «Эксперт» → «Импорт
  глоссария заказчика». Администратор для этого не нужен.

Архив содержит глоссарии заказчика: не передавайте его за пределы контура.

## Обновление

Распаковать новый архив поверх старого и снова запустить установку:

```bash
tar xzf hut_<новая дата>.tar.gz && cd hut
./install.sh
```

Данные, пользователи и настройки сохраняются.

## Обслуживание

| Команда | Что делает |
|---|---|
| `./hut status` | работает ли сервис |
| `./hut check` | проверка установки с подсказками, что делать |
| `./hut logs` | последние записи журнала |
| `./hut stop` / `./hut start` | остановить / запустить |
| `./hut backup` | копия базы сейчас |

Копия базы делается и сама, раз в сутки, в `data/backups/`. Всё ценное лежит в папке `data/` и в файле `.env`
(ключ шифрования токенов) — их и сохранять в резервных копиях сервера.

## Если не работает

Запустите `./hut check`: напротив каждой неудачной проверки написано, что делать. Чаще всего:
- **«портал недоступен»** — серверу нужен выход на https://go.ai-rosatom.ru;
- **порт занят** — поменяйте `HUT_PORT` в `.env` и выполните `./hut restart`.
